PROBLEM STATEMENT
─────────────────
Nouvelle boutique "SALIKHATE NENUPHAR" affichait les produits de l'ancienne
boutique "fashion nova". Les données n'étaient PAS isolées entre les boutiques.

ROOT CAUSE
──────────
1. Table shop_settings manquait colonne 'slug' (identifiant URL)
2. getProducts() récupérait les produits du PREMIER shop au lieu du bon
3. getShopSettings() ne filtrait pas par boutique
4. Aucune vérification que un produit appartient à sa boutique

SOLUTION IMPLEMENTED
───────────────────
✅ Migration Supabase : ajout colonne 'slug' unique
✅ Nouvelle fonction getShopIdBySlug(slug) — convertit URL → ID boutique
✅ Nouvelle fonction getProductsByShopSlug(slug) — récupère produits filtrés
✅ Nouvelle fonction getProductByIdAndSlug(productId, slug) — vérification sécurité
✅ getShopSettings(slug?) — accepte slug optionnel
✅ Mise à jour storefront + page produit + page livraison
